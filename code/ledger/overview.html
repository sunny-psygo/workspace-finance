账本

上次以来

接上系统 PostgreSQL；报销草稿→财务→总经理闭环已通，总经理通过时借费用贷应付写入账本。代码在仓库 code/ledger/。

需要你

没有待决定的事。本机 sudo 密码建议改一次（曾用于安装 PostgreSQL）。生产权限与附件上传还没做。

现状

系统 PostgreSQL 18 在 127.0.0.1:5432，库名 ledger。领域测试覆盖账本平衡/幂等，以及报销状态机与入账。页面 http://127.0.0.1:3210。未做登录、附件、付款回单、工资、结账。

这是什么

复式记账只有一件事：一笔业务写成若干借、贷，两边金额相等，然后落到账户上。报销是这笔分录的来源，不是另一套账。
