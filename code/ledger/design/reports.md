# 报表派生（资产负债 / 利润表）

## 1. 目标与边界

**问题**：结账后需要对外可读的资产负债表与利润表；试算表是科目余额，不是报表行次。

**预期结果**：

1. 资产负债表：按小企业常用行次，从账户余额派生；固定资产列示原价、累计折旧、账面价值。
2. 利润表：指定期间（YYYY-MM）收入/费用发生额派生；排除结转/年结系统分录。
3. 勾稽：资产 = 负债 + 权益 +（收入 − 费用）在未结清损益时成立；结清后收入费用为 0。

**非目标**：完整会小企 01/02 全部行次、现金流量表、合并报表、可配置映射引擎、导出 PDF。

## 2. 认知

报表是**已过账事实的派生视图**，不是第二套账。权威仍在 `Account` / `Entry` / `Posting`。

## 3. 接口

- `GET /api/books/{bookId}/reports/balance-sheet`
- `GET /api/books/{bookId}/reports/income-statement?yearMonth=YYYY-MM`

## 4. 行次映射（本版种子科目）

资产负债表：

| 行 | 来源 |
|---|---|
| 货币资金 | 1002（及日后 1001）余额 |
| 固定资产原价 | 1601 |
| 减：累计折旧 | −1602 的借方口径余额（贷记备抵取绝对值） |
| 固定资产账面价值 | 原价 − 累计折旧 |
| 资产合计 | 上列合计 |
| 应付职工薪酬 | 2211 |
| 应交税费 | 2221 |
| 其他应付款 | 2241 |
| 负债合计 | 上列 |
| 本年利润 | 4103 |
| 未分配利润 | 4104 |
| 权益合计 | 上列 |
| 负债和权益合计 | 负债 + 权益 |

利润表（期间）：

| 行 | 来源 |
|---|---|
| 管理费用等费用 | kind=expense 期间净发生 |
| 营业收入等 | kind=income 期间净发生（种子暂无收入科目时为 0） |
| 利润总额 | 收入 − 费用 |

## 5. 验证

购置 + 折旧后 BS：货币资金/固定资产/应付勾稽；月结后费用进本年利润，BS 仍平衡。
